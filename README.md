# Zero Waste Warriors

A React + Vite frontend prototype for connecting surplus food donors with NGOs.

## Run locally

1. Download `zero-waste-warriors-frontend.zip` from this repository and extract it.
2. Open the extracted folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.

## Prototype features

- Landing page and food listings
- Donor and NGO demo dashboards
- Demo login and request tracking
- Responsive layout

## Note

This is a frontend prototype. Authentication, persistence, APIs, database, and real pickup workflows still need backend integration. Demo data and interactions are not production-ready.
